# Instructions on Web for Agents

This directory contains the web UI of the application and uses pnpm as package manager.

## Pre-commit verification

Before committing changes, run the following.

1. Format the code:

   ```bash
   pnpm run fmt
   ```

2. Lint the code:

   ```bash
   pnpm run lint
   ```

All errors and warnings reported by lint MUST be fixed before committing.
